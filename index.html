01

Nouvelles menaces et vulnérabilités

Pourquoi ce sujet ?

La cybersécurité évolue à une vitesse fulgurante. Chaque jour apporte son lot de nouvelles attaques sophistiquées, de failles critiques découvertes dans des systèmes réputés sûrs, et d'exploitation innovante de l'IA par les cybercriminels. Cette veille est essentielle pour comprendre les risques actuels et anticiper les menaces de demain.

Tendances actuelles

  • Ransomware nouvelle génération : Attaques double/triple extorsion
  • Attaques supply chain : Compromission de la chaîne d'approvisionnement
  • Exploitation de l'IA : Deepfakes, phishing automatisé, malwares adaptatifs
  • Zero-Day : Vulnérabilités exploitées avant leur découverte

Vulnérabilités fréquentes

  • Mauvaises configurations système
  • Interfaces d'administration exposées publiquement
  • Clés API hardcodées dans le code source
  • Conteneurs Docker mal isolés
  • Bases de données accessibles publiquement

Bonnes pratiques de sécurité

  • Mises à jour régulières et automatisées
  • MFA (Authentification multi-facteurs) obligatoire
  • Segmentation réseau stricte
  • Sauvegardes hors ligne (règle 3-2-1)
  • Analyse continue des journaux (SIEM)
02

Cloud Computing (AWS, Azure, Google Cloud)

Pourquoi ce sujet ?

Le cloud computing est devenu incontournable dans les infrastructures modernes. AWS, Azure et Google Cloud Platform représentent aujourd'hui le cœur des systèmes d'information des entreprises. Comprendre ces technologies est essentiel pour tout professionnel de l'infrastructure et de la sécurité.

Tendances du cloud

  • Croissance exponentielle : Migration massive vers le cloud public
  • Multi-cloud & hybride : Combinaison de plusieurs fournisseurs
  • IA et Machine Learning : Services managés d'intelligence artificielle
  • Serverless : Architecture sans serveur (Lambda, Functions)

Comparatif des principaux fournisseurs

Amazon Web Services (AWS)
  • EC2 (machines virtuelles)
  • S3 (stockage objet)
  • Lambda (serverless)
  • RDS (bases de données)
Microsoft Azure
  • Virtual Machines
  • Azure AD (identité)
  • SQL Database
  • App Services
Google Cloud Platform
  • Compute Engine
  • GKE (Kubernetes)
  • BigQuery (analytics)
  • Cloud Functions

Enjeux de sécurité cloud

  • Mauvaises configurations (principales sources de failles)
  • Rôles IAM trop permissifs
  • Buckets S3/Blob publics par erreur
  • Clés API non protégées ou exposées
  • Logs et monitoring non activés

Bonnes pratiques cloud

  • Chiffrement systématique (au repos et en transit)
  • MFA obligatoire sur tous les comptes
  • Infrastructure as Code (Terraform, CloudFormation)
  • Surveillance continue et alertes (CloudWatch, Monitor)
  • Segmentation réseau (VPC, subnets privés)
  • Principe du moindre privilège (Least Privilege)
