Bonjour, je suis Quentin Chapuis

Étudiant au CFAI en BTS SIO option SISR, je me forme aux métiers de l’administration système, du réseau et de la cybersécurité. Je suis actuellement en alternance chez Focal JMLab, une entreprise française fondée en 1979 et reconnue mondialement comme l’un des leaders de l’acoustique haut de gamme. L’entreprise se distingue par son savoir‑faire industriel, ses innovations technologiques (membranes exclusives, matériaux composites, procédés de précision) et sa fabrication majoritairement française. Travailler chez Focal JMLab me permet d’évoluer dans un environnement où l’exigence, la qualité et l’innovation sont au cœur de chaque projet.

J’y participe à la gestion et à la sécurisation des infrastructures informatiques, ce qui me permet de développer mes compétences techniques tout en contribuant au fonctionnement d’une entreprise de renommée internationale.

Veille Technologique

Introduction

Dans le cadre de mon BTS SIO SISR, j’ai mis en place une veille technologique afin de suivre l’évolution des technologies, des menaces et des infrastructures modernes.

J’ai choisi deux thématiques essentielles :

  • Nouvelles menaces et vulnérabilités
  • Cloud computing (AWS, Azure, Google Cloud)

Veille 1 — Nouvelles menaces et vulnérabilités

Pourquoi ce sujet ?

La cybersécurité évolue très rapidement : nouvelles attaques, failles critiques, exploitation de l’IA par les cybercriminels… Ce sujet est essentiel pour comprendre les risques actuels.

Tendances actuelles

  • Ransomware nouvelle génération
  • Attaques supply chain
  • Exploitation de l’IA
  • Zero‑Day

Vulnérabilités fréquentes

  • Mauvaises configurations
  • Interfaces d’administration exposées
  • Clés API dans le code
  • Conteneurs mal isolés
  • Bases de données publiques

Bonnes pratiques

  • Mises à jour régulières
  • MFA obligatoire
  • Segmentation réseau
  • Sauvegardes hors ligne
  • Analyse des journaux

Veille 2 — Cloud Computing (AWS, Azure, Google Cloud)

Pourquoi ce sujet ?

Le cloud est devenu incontournable dans les entreprises. AWS, Azure et Google Cloud sont au cœur des infrastructures modernes.

Tendances du cloud

  • Croissance du cloud public
  • Multi‑cloud et hybride
  • Explosion de l’IA

Comparatif des fournisseurs

  • AWS : EC2, S3, Lambda
  • Azure : VM, Azure AD, SQL Database
  • Google Cloud : GKE, BigQuery

Enjeux de sécurité

  • Mauvaises configurations
  • Rôles IAM trop permissifs
  • Buckets publics
  • Clés API non protégées
  • Logs non activés

Bonnes pratiques cloud

  • Chiffrement systématique
  • MFA obligatoire
  • Infrastructure as Code
  • Surveillance continue
  • Segmentation réseau

Mes Réalisations

Script PowerShell — Blocage du Microsoft Store

J’ai développé un script PowerShell permettant de bloquer l’accès au Microsoft Store pour l’ensemble de l’entreprise. Le script modifie la valeur d’une clé de registre Windows afin de désactiver complètement le Store sur tous les postes concernés.

Après validation, j’ai déployé ce script à grande échelle via Microsoft Intune, en utilisant les stratégies de déploiement automatisées. Cela a permis une application uniforme, rapide et sécurisée sur l’ensemble du parc informatique.

Ce projet m’a permis de travailler sur : — l’automatisation PowerShell — la gestion de stratégies de sécurité — le déploiement à distance via Intune — la standardisation des postes utilisateurs

Active Directory

Gestion des utilisateurs, des groupes et des droits d’accès. Création de comptes, organisation des OU, et application de règles de sécurité.

Routage Cisco

Configuration de routeurs et de switches, mise en place de VLANs, routage statique et segmentation réseau pour améliorer la sécurité et les performances.
